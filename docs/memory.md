# 记忆库

后端起在 `记忆机/工具/mem.py`，纯标准库，没有常驻进程，一个子命令一件事。索引是 sqlite 的 FTS5，`tokenize='trigram'`，中文至少三个连续字才命中，标点不跨。

## 四个动作

`store` 记一件。必填 `--title`，可选 `--said`（他说的）、`--heart`（我心里的）、`--who`（默认老丁）、`--domain`、`--occurred`（事情实际发生的时间，补旧事才填）、`--dry-run`。落件是先在临时文件里写好再 rename，写锁最多等 3 秒，流水和索引在同一个事务里，写完两边都对得上。

域只收白名单：官方 15 个域加 `0_此刻`，再加 `未判`。`--domain` 不传或给 `auto` 一律记 `未判`，2026-11-06 起不再自动判域——全量回放证明关键词判准约三成、向量约四成六，都不够，宁可不判。历史标签（`6_技术与工具`、`9_会话归档`、`4_干活纪律`、`2_关系与锚`、`3_相处准则`、`教训`）只读，显式传了会被拒。

`search` 查。默认混合检索，返回最多 5 条、封顶 2 KB，`--limit` 最多 10。

`get` 取一件原文，按件名取，`--max` 默认 8000 字节，超了截断并给提示。

`status` 体检。件数、漂移样本、最后写入、库大小。

四个动作都有硬超时，默认 8 秒，到点抛 `TooSlow` 退出并报错，不会把一次调用挂住。

## 返回什么

`search` 每条约 300 字节：件名、标题、时间、域、事件时间、片段、分数。混合模式下分数带 `fts_rank`、`vec_rank` 和 `rrf`，方便看是哪一路把它捞上来的；纯 FTS 模式只有 bm25 分和 `fts_rank`。总量封顶 2000 字节，装不下就截断，不会把一条全文塞进来。

`status` 返回件数、索引条目数、漂移样本、最后写入时间和库大小，末尾另带两行：`运行/health.json` 的健康摘要和向量覆盖率。

`记忆机/状态.json` 是给人看的 1 KB 状态卡，开局读它就够，别去翻目录。

## 域的三档

`verify` 是只读体检，拿磁盘、索引、域三项对账：不建表、不写锁、不动流水和正本。域的处理分三档。

官方域（15 域加 `0_此刻`）合法，直接放过。历史标签只在旧件里宽容——落件日期早于 `20261106` 的件带历史标签，记进 `legacy_domain`，不算红；同一天及以后的新件，域不是官方域就算 `bad_domain`，判红。域缺失按 `未判` 记，只计数 `empty_domain`，不算坏。

判 `ok` 要同时满足：索引能开、磁盘件数等于索引件数、`missing` 和 `extra` 都空、`index_docs` 等于 `index_fts`、没有 `bad_domain`。不满足就 exit 1，输出一份 JSON，机器好读。

## 混合检索

只有一条通道：百炼 `text-embedding-v3`，1024 维。

```
查询 ─┬─ FTS5 取 40 个候选 ──┐
      └─ 查询向量算余弦取 40 ─┴─ RRF(k=60) 融合 ── 取前 N
```

FTS 候选 40、向量候选 40，两路各自从 1 排名，融合分是 `1/(60+r_f) + 1/(60+r_v)`，缺哪一路就少加那一项。查询向量和索引向量必须同源，都是百炼，绝不混算。

超时 8 秒。嵌入超时、没有向量索引、key 读不到、网络断了，都不报错，静默降级成纯 FTS，返回 `mode=fts`，带上 `provider` 和 `degraded_reason`。降级后 FTS 那一跑只给 3 秒余量。

## 一份索引文件

向量只有一份 `记忆机/向量_v2.bailian.jsonl`，一行一件：`{file, sha1, model, dim, provider, v}`。没有第二份、没有备用通道，也不存在「两个 provider 融合」这种事。文件不在就退 FTS，文件在但某件变了，`maintain --vector` 按 sha1 只重算变的那批。

文本索引是 `记忆机/索引_v2.db`，`docs` 表存元数据，`docs_fts` 存标题和正文。库用回滚日志不用 WAL，因为 `/tmp` 和部分 FUSE 目录不支持 `-shm`。

## 维护入口

```
mem.py maintain --reindex     重建文本索引（复用 reindex）
mem.py maintain --backup      打一份 备份/记忆机_<ts>.tar.gz
mem.py maintain --vector      增量补向量，sha1 没变就复用
mem.py verify                 只读对账，ok 时 exit 0
```

`--vector` 的 provider 只认 `bailian`，写 `auto` 也走它。

日常维护交给调度器，不手跑：03:10 备份、04:10 整理。整理一次跑完 55 秒预算：体检、重建索引、消费待记、补向量、写 `运行/health.json`。看后台行不行，读 `health.json` 或 `mem_status` 最后两行，别翻日志猜。
